# Projeto POO

Projeto acadêmico desenvolvido durante a faculdade com o objetivo de aplicar, na prática, os conhecimentos de **Programação Orientada a Objetos (POO)** aprendidos em sala de aula.

## Sobre o projeto

A aplicação foi desenvolvida em Java e trabalha com o domínio de gerenciamento de gado, incluindo diferentes raças e informações como peso, idade e histórico médico.

## Objetivo

O principal objetivo deste projeto é consolidar conceitos fundamentais de POO por meio da construção de uma aplicação prática, organizada em classes com responsabilidades bem definidas.

## Conceitos aplicados

- Classes e objetos
- Encapsulamento
- Herança e especialização de classes
- Polimorfismo
- Tratamento de exceções personalizadas
- Organização e reutilização de código

## Tecnologias utilizadas

- Java
- IntelliJ IDEA

## Contexto acadêmico

Este repositório representa uma atividade realizada durante a graduação para demonstrar a aplicação dos conteúdos estudados na disciplina de Programação Orientada a Objetos.
